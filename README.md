## What it does

`main.py` (Python 3, stdlib only, deterministic, no network) writes one
out-of-office auto-reply — as if a houseplant sent it — to
`/output/entry.txt`. The line is 111 characters, a single line, and the
program refuses to write it if it ever falls outside 1–120 characters.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
